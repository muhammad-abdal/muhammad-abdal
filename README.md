### `03 / INTELLIGENCE`

# AI IS NOT THE PRODUCT.<br>IT IS A NEW WAY TO INTERACT WITH ONE.

I use AI as a product capability rather than a decorative feature.

<div align="center">

`INPUT` → `CONTEXT` → `INTELLIGENCE` → `ACTION` → `EXPERIENCE`

</div>

The interesting question is not *"where can AI be added?"* — it's:

> **"Where does intelligence make the experience meaningfully better?"**

That distinction shapes how I approach AI-powered mobile applications.
